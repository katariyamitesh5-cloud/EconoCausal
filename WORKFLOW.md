# Project Workflow

## End-to-End Process

1. Generate or load customer data.
2. Validate the dataset.
3. Preprocess the data.
4. Build the causal relationship.
5. Run Double Machine Learning.
6. Calculate treatment effects.
7. Generate pricing recommendations.
8. Serve recommendations through FastAPI.
9. Display analytics on the web dashboard.

## Output

The final system provides customer-level treatment effects and dynamic pricing recommendations based on the estimated causal impact of discounts.
