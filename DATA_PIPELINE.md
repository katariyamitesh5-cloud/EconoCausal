# Data Pipeline

The EconoCausal data pipeline follows these stages:

1. Load customer data.
2. Validate the dataset.
3. Preprocess customer features.
4. Prepare treatment and outcome variables.
5. Estimate treatment effects using Double Machine Learning.
6. Store the resulting treatment effects.
7. Generate customer-level pricing recommendations.

The pipeline helps maintain a consistent flow from raw customer data to final pricing recommendations.
