# Contributing to EconoCausal

## Getting Started

1. Clone the repository.
2. Create and activate the virtual environment.
3. Install project dependencies.
4. Run the application locally.

## Development Guidelines

- Keep Python code clean and readable.
- Use meaningful variable and function names.
- Test changes before committing.
- Do not commit the virtual environment.
- Keep sensitive information in the `.env` file.

## Before Pushing

Run the required scripts and verify that:

- Dataset validation passes.
- DML analysis runs successfully.
- API endpoints work correctly.
- The dashboard loads properly.
