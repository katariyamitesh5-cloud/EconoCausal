# Model Documentation

## Double Machine Learning

EconoCausal uses Double Machine Learning (DML) to estimate the causal effect of discounts on sales.

## Treatment

Discount is the treatment variable.

## Outcome

Sales is the outcome variable.

## Treatment Effect

The model estimates the individual treatment effect for each customer.

These treatment effects are then used by the pricing recommendation system to classify customers into Low, Medium, and High Discount strategies.
